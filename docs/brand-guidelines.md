# Euro Factory · Identidad amarillo ámbar y grafito

Referencia visual aportada por el cliente: carteles exteriores de **Euro Factory** y **ECUS Motors**. La señalética combina fondo metálico grafito oscuro, negro, tipografía blanca y letras amarillo ámbar iluminadas. La paleta del sitio es **negro + ámbar**, nunca rojo racing.

## Paleta principal
- Negro profundo / fondo: `#090A0B`
- Grafito / superficie: `#111214` y `#1B1C1F`
- Ámbar señalética / CTA: `#F2B32E`
- Ámbar claro / hover y detalles: `#FFC65B`
- Marfil técnico / sección clara: `#F6F2E9`
- Texto blanco: `#FFFFFF`
- Texto secundario en fondos oscuros: `#B4B4B8`

## Criterio visual
La base es grafito, no un amarillo de advertencia a pantalla completa. Usar ámbar exclusivamente para botones principales, titulares destacados, estados activos, numeración, líneas y detalles; textos negros sobre superficies amarillas para un contraste claro. Evitar rojo, verde o azul como acentos decorativos. Mantener fotografías automotrices, tipografía Barlow Condensed, diseño limpio, interfaces móviles y accesibilidad.

Conservar datos reales, rutas SEO y perfiles de sedes. El selector prepara la visita y no simula potencia. Los bloques de confianza explican el proceso; no usan testimonios ficticios. Carrusel manual y galería ampliable por teclado. El formulario solo prepara WhatsApp.

El archivo performance-hero.webp es una imagen de ambientación generada; las fotos de galería proceden del material original del taller.
